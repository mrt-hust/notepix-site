Fonctionnement

Trois clics entre l’agacement et le diff.

1

Invoquez le panneau

Appuyez sur Alt+Shift+A (Mac : ⌥⇧A) sur votre app, ou cliquez l’icône de la barre d’outils. Chargement auto sur localhost.

2

Marquez ce qui vous gêne

Épinglez une Note sur n’importe quel élément, tracez un Frame autour d’une zone, ou esquissez au Pen. Écrivez le changement en mots simples.

Les marques

Quatre façons de pointer. Un brief précis.

1NOTE cliquez un élément · dites le changement

Pointez la chose. Dites ce que vous voulez.

Choisissez Note et cliquez — une épingle numérotée se pose sur l’élément, vous tapez le changement. Tracez un Frame autour d’une zone, ou gribouillez avec le Pen.

Joignez des captures propres par marque, et déposez des @références vers d’autres éléments — « aligne ceci sur @Heading ».

2SOURCE src/demo/components/UpgradeButton.jsx:6:25

Chaque marque connaît le code derrière elle.

Pas div.css-1q2w3e — mais <button> in UpgradeButton — src/components/UpgradeButton.jsx:6. React 18/19, Vite, Next.js, CRA. Votre agent ouvre le bon fichier au lieu de le chercher au grep.

Chaque marque capture aussi le style calculé et la liste de classes de l’élément. Page non React ? Repli sur un sélecteur CSS précis.

3MEASURE font 14px · pad 18 20 · gap ←18 →18

Citez de vrais pixels, pas des impressions.

Au survol, un relevé digne des DevTools : padding, margin, et l’écart mesuré vers chaque voisin — en pixels réellement rendus.

Une note peut donc dire « 24px entre ces deux-là — mets 8 » sans jamais ouvrir les DevTools.

4BRIEF markdown · plain text · JSON · Claude in Chrome · MCP

Un clic. Un brief que tout agent peut exécuter.

Copy for AI regroupe chaque marque ouverte — élément, source, style, instruction — en un seul collage. Cinq formats, dont un prompt de passation pour Claude Code via Claude in Chrome.

Les captures partent tamponnées du badge #id de leur marque — images et instructions ne peuvent pas se séparer.

Épinglez. Votre agent corrige. La carte se coche seule.

Une commande enregistre le serveur local Notepix auprès de chaque agent de codage de votre machine. Votre agent tire chaque marque directement du navigateur et passe sa carte en DONE sous vos yeux à mesure qu’il corrige.

Dites « corrige chaque marque dès que je l’épingle » et continuez à cliquer dans votre app pendant que les diffs tombent. Le tout sur 127.0.0.1.

FAQ

Questions, réponses.

Faut-il React pour que ça marche ?

Non — Notepix annote n’importe quelle page. Sur un build React de dev (Vite, Next.js, CRA ; React 18 et 19), chaque marque enregistre en plus le nom du composant et le fichier:ligne source derrière l’élément. Sur les builds de production et les pages non React, elle retombe sur un sélecteur CSS précis. La résolution de source Vue et Svelte est sur la feuille de route.

Avec quels agents IA fonctionne-t-il ?

Tout ce dans quoi vous pouvez coller : Claude Code, Cursor, GitHub Copilot, Windsurf, Codex, Aider, une simple fenêtre de chat. Le brief est du texte brut dans votre presse-papiers — aucun compte ni configuration requis. Vous pouvez aussi sauter le collage, de deux façons : avec Claude Code connecté via Claude in Chrome (choisissez le format de passation, il lit les marques sur la page), ou en ajoutant le serveur MCP Notepix optionnel — une commande, npx -y notepix-mcp setup, l’enregistre auprès de chaque agent de codage de votre machine — pour que votre agent récupère lui-même marques et captures et les coche à mesure qu’il corrige.

Ça marche sur les préviews Lovable, Replit, v0 ou Bolt ?

Oui — cliquez sur l’icône Notepix de la barre d’outils sur n’importe quelle page http(s), préviews cloud comprises, et annotez. Sur les serveurs de dev localhost, Notepix se charge automatiquement après chaque reload ; l’auto-chargement en un clic pour les domaines de préview est la prochaine mise à jour prévue.

Où vivent mes notes ?

Dans le stockage local d’extension de Chrome, indexées par page et par route SPA. Sur les serveurs de dev localhost, Notepix se charge automatiquement : vos notes sont toujours là après chaque reload. Vous pouvez exporter les marques d’une page en fichier JSON et les importer n’importe où.

Qu’est-ce que Notepix envoie sur le réseau ?

Rien ne quitte votre ordinateur — jusqu’à ce que vous saisissiez une clé de licence. Ensuite, il n’existe qu’un seul type de requête Internet : la vérification de votre clé auprès de l’API de licences Gumroad, à l’activation puis au plus une fois par semaine. Elle transporte la clé et l’id du produit, jamais le contenu des pages, les notes ou les captures. Si vous activez la connexion MCP optionnelle, celle-ci va vers 127.0.0.1 — votre propre machine — et nulle part ailleurs. La politique complète est sur la page de confidentialité.

Que se passe-t-il à la fin de l’essai ?

Créer de nouvelles marques demande le déblocage unique à 6,43 $. Tout ce que vous avez déjà créé reste visible, copiable, exportable et supprimable pour toujours — vos notes sont vos données.

Le raccourci clavier ne fait rien ?

Alt+Shift peut entrer en conflit avec le changement de disposition clavier, surtout sous Windows. Ouvrez chrome://extensions/shortcuts et réassignez « Toggle the Notepix panel » à ce que vous voulez — l’icône de la barre d’outils et le menu clic droit fonctionnent toujours.

Chrome uniquement ?

Chrome 116+ et Edge basé sur Chromium (testé). Une fiche Edge Add-ons et d’autres navigateurs sont sur la feuille de route.
