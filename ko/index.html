사용 방법

클릭 세 번이면, 거슬림에서 diff까지.

1

패널 불러오기

실행 중인 앱에서 Alt+Shift+A(Mac: ⌥⇧A)를 누르거나 툴바 아이콘을 클릭하세요. localhost에서는 자동 로드됩니다.

2

거슬리는 곳에 마크

아무 요소에나 Note를 핀하고, 영역 둘레에 Frame을 드래그하고, Pen으로 스케치하세요. 변경 내용은 평범한 말로 적으면 됩니다.

마크

가리키는 방법 네 가지. 정확한 브리프 하나.

Note를 고르고 클릭하면 — 번호 핀이 요소에 내려앉고, 변경 내용을 입력합니다. 영역 둘레에 Frame을 드래그하거나 Pen으로 자유롭게 그리세요.

마크마다 깔끔한 스크린샷을 첨부하고, 다른 요소를 가리키는 @참조를 넣으세요 — “이걸 @Heading과 맞춰줘”.

2SOURCE src/demo/components/UpgradeButton.jsx:6:25

모든 마크는 뒤에 있는 코드를 압니다.

div.css-1q2w3e가 아니라 <button> in UpgradeButton — src/components/UpgradeButton.jsx:6. React 18/19, Vite, Next.js, CRA. 에이전트가 grep으로 뒤지는 대신 바로 그 파일을 엽니다.

각 마크는 요소의 계산된 스타일과 클래스 목록도 스냅샷합니다. React가 아닌 페이지라면? 정밀한 CSS 셀렉터로 대체됩니다.

3MEASURE font 14px · pad 18 20 · gap ←18 →18

감이 아니라 실제 픽셀로.

호버하면 DevTools급 정보가 표시됩니다: 패딩, 마진, 그리고 이웃 요소까지의 측정된 간격 — 실제로 렌더링된 픽셀입니다.

그래서 DevTools를 열지 않고도 “이 사이 24px — 8로 줄여줘”라고 쓸 수 있습니다.

디테일

이것도 기본 제공.

키보드 우선

Alt+Shift+N은 패널을 열지 않고 노트를 핀합니다. 패널 안에서는 N F D S로 모드를 전환합니다.

깔끔한 스크린샷 크롭

📷는 그 컴포넌트만 잘라냅니다 — Notepix 자체 핀은 먼저 제거됩니다.

SPA 인식, 페이지별 저장

라우트마다 자기 마크를 유지하고, 패널은 클라이언트 사이드 내비게이션을 따라갑니다.

내보내기 / 가져오기

JSON으로 내보내고 JSON으로 가져오기 — 동료의 마크를 병합하거나 컴퓨터를 옮기세요.

기본은 깨끗한 페이지

핀은 마킹 중에만 그려집니다. 패널을 숨기면 앱은 언제든 보여줄 수 있는 상태로 남습니다.

스스로 연결되는 이미지

모든 스크린샷에 마크의 #id가 찍힙니다 — 에이전트는 붙여넣은 순서가 아니라 배지로 이미지와 지시를 매칭합니다.

일회용이 아닌 루프

마크를 ✓ 완료로 체크하면 — 참고용으로 남되 다음 복사에서는 빠집니다. 모든 삭제에는 Undo가 있습니다.

방해되지 않게

Ghost 모드는 호버하기 전까지 패널을 흐리게 둡니다. 어디로든 드래그하고, 모든 가장자리에서 크기를 조절하세요.

도움말은 ? 하나로

?를 누르면 30초 가이드가 다시 열립니다. 단축키는 chrome://extensions/shortcuts에서 재지정하세요.

설계부터 프라이빗

앱은 절대 내 컴퓨터를 떠나지 않습니다.

서버 없음, 계정 없음

백엔드가 없습니다. 노트·스크린샷·소스 경로는 내 컴퓨터의 Chrome 로컬 저장소에만 있습니다 — 다른 어디에도 없습니다.

추적 없음

분석도, 텔레메트리도, 크래시 리포트도 없습니다. 무엇을 마크하든 당신의 일입니다.

네트워크 요청은 단 한 종류

라이선스 키를 입력하기 전까지 요청 0건 — 그 후에도 Gumroad 키 검증 한 종류뿐. 페이지나 노트는 절대 보내지 않습니다.

FAQ

궁금한 점, 답해드립니다.

React가 있어야 하나요?

아니요 — Notepix는 어떤 페이지든 마크할 수 있습니다. React dev 빌드(Vite, Next.js, CRA; React 18·19)에서는 각 마크에 요소 뒤의 컴포넌트 이름과 소스 파일:라인이 추가로 기록됩니다. 프로덕션 빌드나 React가 아닌 페이지에서는 정밀한 CSS 셀렉터로 대체됩니다. Vue·Svelte 소스 해석은 로드맵에 있습니다.

어떤 AI 에이전트와 함께 쓸 수 있나요?

붙여넣을 수 있는 곳이면 어디든: Claude Code, Cursor, GitHub Copilot, Windsurf, Codex, Aider, 일반 채팅창. 브리프는 클립보드에 담기는 일반 텍스트라 계정도 설정도 필요 없습니다. 붙여넣기를 아예 생략하는 방법도 둘 있습니다: Claude in Chrome으로 연결된 Claude Code를 쓰거나(핸드오프 포맷을 고르면 페이지에서 마크를 직접 읽어갑니다), 선택 사항인 Notepix MCP 서버를 추가하세요 — 명령 하나, npx -y notepix-mcp setup이면 컴퓨터의 모든 코딩 에이전트에 등록되고 — 에이전트가 마크와 스크린샷을 직접 가져가 수정하면서 하나씩 완료 처리합니다.

Lovable, Replit, v0, Bolt 프리뷰에서도 되나요?

네 — 클라우드 프리뷰를 포함한 모든 http(s) 페이지에서 Notepix 툴바 아이콘을 클릭하고 마크하세요. localhost 개발 서버에서는 새로고침할 때마다 Notepix가 자동 로드됩니다. 프리뷰 도메인 원클릭 자동 로드는 다음 업데이트로 예정되어 있습니다.

노트는 어디에 저장되나요?

Chrome의 로컬 확장 프로그램 저장소에 페이지·SPA 라우트별로 저장됩니다. localhost 개발 서버에서는 Notepix가 자동 로드되므로 새로고침해도 노트가 그대로 남습니다. 어떤 페이지의 마크든 JSON 파일로 내보내고 어디서든 가져올 수 있습니다.

Notepix는 네트워크로 무엇을 보내나요?

라이선스 키를 입력하기 전까지는 아무것도 컴퓨터를 떠나지 않습니다. 그 후에도 인터넷 요청은 정확히 한 종류뿐: 활성화 시점과 최대 주 1회, Gumroad 라이선스 API로 키를 검증하는 요청입니다. 여기에는 키와 제품 ID만 담기며 페이지 내용·노트· 스크린샷은 절대 포함되지 않습니다. 선택 사항인 MCP 연결을 켜면 그 통신은 127.0.0.1 — 내 컴퓨터 — 로만 오갑니다. 전체 정책은 개인정보 페이지에 있습니다.

체험 기간이 끝나면 어떻게 되나요?

새 마크를 만들 때 일회성 $6.43 해제를 요청합니다. 이미 만든 것은 모두 영구히 보기·복사·내보내기·삭제할 수 있습니다 — 노트는 당신의 데이터니까요.

키보드 단축키가 안 먹혀요?

Alt+Shift는 특히 Windows에서 키보드 레이아웃 전환과 충돌할 수 있습니다. chrome://extensions/shortcuts를 열어 “Toggle the Notepix panel”을 원하는 키로 다시 지정하세요 — 툴바 아이콘과 우클릭 메뉴는 언제나 동작합니다.

Chrome 전용인가요?

Chrome 116+ 및 Chromium 기반 Edge(테스트 완료). Edge Add-ons 등록과 다른 브라우저 지원은 로드맵에 있습니다.
