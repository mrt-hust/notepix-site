マークの種類

指し方は 4 つ。ブリーフは 1 つ。

1NOTE 任意の要素をクリック · 変更を伝える

指を差して、望みを言う。

Note を選んでクリック——番号付きピンが要素に着地し、変更内容を入力。Frame で範囲を囲み、Pen で走り書きも。

マークごとにクリーンなスクリーンショットを添付。 @references で他要素も参照——「これを @Heading と揃えて」。

2SOURCE src/demo/components/UpgradeButton.jsx:6:25

どのマークも、裏のコードを知っている。

div.css-1q2w3e ではなく、 <button> in UpgradeButton — src/components/UpgradeButton.jsx:6。React 18/19、Vite、Next.js、CRA。エージェントは grep せずに正しいファイルを開く。

各マークは要素の計算済みスタイルと class 一覧も記録。 React 以外のページでは精密な CSS セレクターにフォールバック。

3MEASURE font 14px · pad 18 20 · gap ←18 →18

雰囲気ではなく、実ピクセルで語る。

ホバーすると DevTools 級の読み取り：padding、margin、そして隣要素までの 実測ギャップ——実際に描画されたピクセルで。

だからメモに「この間は 24px——8 にして」と書ける。 DevTools を開かずに。

ループ

ピン留め。エージェントが修正。カードは自動でチェック。

✓LIVE npx -y notepix-mcp setup · プラグアイコン → 緑

クリップボード不要：エージェントが自らマークを読む。

コマンド 1 つで、ローカルの Notepix サーバーをマシン上のすべてのコーディングエージェントに登録。エージェントはブラウザから直接マークを取得し、修正するたびに目の前でカードを DONE に返す。

「ピン留めするそばから直して」と言って、diff が届く間もアプリをクリックし続ける。すべて 127.0.0.1 の上で。

ディテール

ほかにも、これだけ。

キーボード最優先

Alt+Shift+N でパネルを開かずにメモをピン留め。パネル内では N F D S でモード切替。

クリーンな切り抜き

📷 はそのコンポーネントだけを切り抜く——Notepix 自身のピンは先に除去。

SPA 対応、ページ単位

ルートごとにマークを保持。パネルはクライアントサイドの遷移に追従。

エクスポート / インポート

JSON で出して、JSON で入れる——チームメイトのマークを統合、マシンの引っ越しも。

デフォルトでページは綺麗

ピンが描かれるのはマーク中だけ。パネルを隠せばアプリは見せられる状態のまま。

画像は自ら紐づく

全スクリーンショットにマークの #id を刻印——エージェントは貼り付け順ではなくバッジで画像と指示を対応付ける。

一発勝負ではなく、ループ

マークを ✓ 完了に——参照用に残りつつ、次のコピーからは外れる。削除はいつでも Undo 可能。

邪魔をしない

Ghost モードはホバーするまでパネルを淡く。どこへでもドラッグ、どの辺からでもリサイズ。

ヘルプは ? ひとつ

? で 30 秒ガイドを再表示。ショートカットは chrome://extensions/shortcuts で変更。

設計からプライベート

アプリがあなたのマシンを離れることはない。

サーバーなし、アカウントなし

バックエンドなし。メモ・スクリーンショット・ソースパスは、あなたのマシンの Chrome ローカルストレージだけに保存——ほかのどこにも。

トラッキングなし

アナリティクスも、テレメトリも、クラッシュレポートもなし。何を注釈するかはあなただけのもの。

ネットワーク通信は 1 種類だけ

ライセンスキーを入れるまでリクエストはゼロ——その後も 1 種類だけ： Gumroad へのキー確認。ページやメモは決して送らない。

FAQ

疑問に、答えを。

React は必須ですか？

いいえ——Notepix はどんなページにもマークできます。React の開発ビルド（Vite、Next.js、CRA。React 18 と 19）では、各マークに要素の裏のコンポーネント名とソースの file:line も記録します。プロダクションビルドや React 以外のページでは精密な CSS セレクターにフォールバック。Vue と Svelte のソース解決はロードマップにあります。

どの AI エージェントで使えますか？

貼り付けられる相手ならなんでも：Claude Code、Cursor、GitHub Copilot、Windsurf、Codex、 Aider、普通のチャット画面でも。ブリーフはクリップボード上のプレーンテキスト——アカウントも設定も不要です。貼り付け自体を省く方法も 2 つ：Claude in Chrome で接続した Claude Code（ハンドオフ形式を選べばページからマークを直接読み取ります）、または任意の Notepix MCP サーバーの追加——コマンド 1 つ、 npx -y notepix-mcp setup がマシン上の全コーディングエージェントに登録——でエージェント自身がマークとスクリーンショットを取得し、直すたびにチェックを付けていきます。

Lovable、Replit、v0、Bolt のプレビューでも動きますか？

はい——どの http(s) ページでもツールバーの Notepix アイコンをクリックすればマークできます。クラウドのプレビューも対象です。localhost の開発サーバーではリロードのたびに Notepix が自動ロード。プレビュードメインのワンクリック自動ロードは次のアップデートで予定しています。

メモはどこに保存されますか？

Chrome のローカル拡張ストレージに、ページごと・SPA ルートごとに保存されます。 localhost の開発サーバーでは自動ロードされるので、リロードしてもメモはそのまま。任意のページのマークを JSON ファイルとしてエクスポートし、どこでもインポートできます。

Notepix はネットワークに何を送りますか？

何もマシンの外に出ません——ライセンスキーを入力するまでは。それ以降もインターネット通信は 1 種類だけ：アクティベーション時と最大週 1 回、 Gumroad のライセンス API へのキー確認です。送られるのはキーと製品 id のみで、ページ内容・メモ・スクリーンショットは決して含まれません。任意の MCP 接続を有効にしても、それは 127.0.0.1——あなた自身のマシン——にしか行きません。全文は プライバシーページにあります。

トライアルが終わるとどうなりますか？

新規マークの作成時に $6.43 の買い切りアンロックを求められます。すでに作ったものは、表示・コピー・エクスポート・削除がずっと可能——メモはあなたのデータです。

キーボードショートカットが効かない？

Alt+Shift は、特に Windows でキーボードレイアウト切替と衝突することがあります。 chrome://extensions/shortcuts を開いて「Toggle the Notepix panel」を好きなキーに割り当て直してください——ツールバーアイコンと右クリックメニューは常に使えます。

Chrome だけですか？

Chrome 116+ と Chromium ベースの Edge（テスト済み）。Edge Add-ons への掲載と他ブラウザはロードマップにあります。
