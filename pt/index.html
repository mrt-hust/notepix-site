As marcas

Quatro jeitos de apontar. Um brief preciso.

1NOTE clique em qualquer elemento · diga a mudança

Escolha Note e clique — um pin numerado pousa no elemento e você digita a mudança. Arraste um Frame ao redor de uma área ou rabisque com o Pen.

Anexe capturas limpas por marca e solte @referências a outros elementos — “deixe isto igual ao @Heading”.

2SOURCE src/demo/components/UpgradeButton.jsx:6:25

Cada marca conhece o código por trás.

Não div.css-1q2w3e — mas <button> in UpgradeButton — src/components/UpgradeButton.jsx:6. React 18/19, Vite, Next.js, CRA. Seu agente abre o arquivo certo em vez de caçá-lo com grep.

Cada marca também fotografa o estilo computado e a lista de classes do elemento. Página sem React? Ele recorre a um seletor CSS preciso.

3MEASURE font 14px · pad 18 20 · gap ←18 →18

Cite pixels reais, não impressões.

Ao passar o mouse aparece uma leitura nível DevTools: padding, margin e o espaço medido até cada vizinho — pixels reais renderizados.

Assim uma nota pode dizer “24px entre estes — deixe 8” sem nunca abrir o DevTools.

4BRIEF markdown · plain text · JSON · Claude in Chrome · MCP

Um clique. Um brief que qualquer agente executa.

O Copy for AI empacota cada marca aberta — elemento, fonte, estilo, instrução — em um único colar. Cinco formatos, incluindo um prompt de handoff para o Claude Code via Claude in Chrome.

As capturas saem carimbadas com o selo #id da marca — imagens e instruções não se separam.

Detalhes

Também na caixa.

Teclado em primeiro lugar

Alt+Shift+N fixa uma nota sem abrir o painel. Dentro dele, N F D S trocam de modo.

Recortes de captura limpos

A 📷 recorta só aquele componente — os pins do próprio Notepix são removidos antes.

Ciente de SPA, por página

Cada rota mantém suas marcas; o painel acompanha sua navegação client-side.

Exportar / importar

JSON para fora, JSON para dentro — mescle as marcas de um colega ou troque de máquina.

Página limpa por padrão

Os pins só aparecem enquanto você marca. Esconda o painel e seu app continua apresentável.

Imagens que se amarram sozinhas

Cada captura sai carimbada com o #id da marca — agentes casam imagem e instrução pelo selo, não pela ordem de colagem.

Um loop, não um tiro único

Marque uma nota como ✓ feita — ela fica de referência mas sai da próxima cópia. Toda exclusão oferece Undo.

Fica fora do seu caminho

O modo Ghost esmaece o painel até você passar o mouse. Arraste para onde quiser, redimensione por qualquer borda.

A ajuda está a um ? de distância

O ? reabre o guia de 30 segundos. Reatribua atalhos em chrome://extensions/shortcuts.

FAQ

Perguntas, respondidas.

Preciso de React para funcionar?

Não — o Notepix marca qualquer página. Em um build dev de React (Vite, Next.js, CRA; React 18 e 19) cada marca registra também o nome do componente e o arquivo:linha fonte por trás do elemento. Em builds de produção e páginas sem React, ele recorre a um seletor CSS preciso. Resolução de fonte para Vue e Svelte está no roadmap.

Com quais agentes de IA ele funciona?

Qualquer lugar onde você possa colar: Claude Code, Cursor, GitHub Copilot, Windsurf, Codex, Aider, uma janela de chat comum. O brief é texto puro na sua área de transferência — sem conta nem configuração. Você também pode pular o colar por completo, de dois jeitos: com o Claude Code conectado pelo Claude in Chrome (escolha o formato de handoff e ele lê as marcas direto da página), ou adicionando o servidor MCP opcional do Notepix — um comando, npx -y notepix-mcp setup, o registra em cada agente de código da sua máquina — para o agente puxar sozinho as marcas e capturas e ir riscando cada uma conforme corrige.

Funciona em previews do Lovable, Replit, v0 ou Bolt?

Sim — clique no ícone do Notepix na barra de ferramentas em qualquer página http(s), previews na nuvem incluídos, e marque à vontade. Em servidores dev no localhost o Notepix carrega sozinho a cada reload; o carregamento automático com um clique para domínios de preview é a próxima atualização planejada.

Onde ficam minhas notas?

No armazenamento local de extensões do Chrome, por página e por rota de SPA. Em servidores dev no localhost o Notepix carrega sozinho, então as notas continuam lá após cada reload. Você pode exportar as marcas de qualquer página como arquivo JSON e importá-las onde quiser.

O que o Notepix envia pela rede?

Nada sai do seu computador — até você inserir uma chave de licença. A partir daí existe exatamente um tipo de requisição: verificar sua chave na API de licenças da Gumroad na ativação e no máximo uma vez por semana. Ela carrega a chave e o id do produto, nunca conteúdo de página, notas ou capturas. Se você ligar a conexão MCP opcional, essa vai para 127.0.0.1 — sua própria máquina — e para nenhum outro lugar. A política completa está na página de privacidade.

O que acontece quando o teste acaba?

Criar marcas novas pede o desbloqueio único de $6.43. Tudo o que você já fez continua visível, copiável, exportável e apagável para sempre — suas notas são seus dados.

O atalho de teclado não faz nada?

Alt+Shift pode conflitar com a troca de layout de teclado, principalmente no Windows. Abra chrome://extensions/shortcuts e reatribua “Toggle the Notepix panel” para o que preferir — o ícone da barra e o menu de contexto sempre funcionam.

Só Chrome?

Chrome 116+ e Edge baseado em Chromium (testado). Uma listagem no Edge Add-ons e outros navegadores estão no roadmap.
